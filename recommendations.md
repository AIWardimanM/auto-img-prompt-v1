# Aturan rekomendasi (default per langkah)

Dipakai saat pengguna mengetik "rekomendasi", "terserah", "bingung", "lewati", atau memilih mode "ikuti rekomendasi semua". Setiap rekomendasi disertai alasan SATU kalimat dan boleh ditolak pengguna. Pilih berdasarkan tema dan sumber, bukan selera.

## Platform
Tanyakan dulu (platform tidak bisa disimpulkan). Bila pengguna tidak tahu: ChatGPT Image atau Gemini untuk infografis bersisi teks, karena keduanya paling andal merender teks panjang.

## Ukuran
| Tema/penggunaan | Rasio |
|---|---|
| Slide, presentasi, rundown mendatar | 16:9 |
| Materi untuk HP, story | 9:16 atau 4:5 |
| Dokumen cetak | A4/A3 portrait |
Kualitas tinggi (2K-4K) bila untuk cetak; selain itu standar.

## Gaya (3A)
| Tema | Gaya |
|---|---|
| Dokumen resmi, kinerja, hukum, keuangan, notulen | Elegan konsultan |
| Acara, rekreasi, promosi | Ilustratif |
| Ada dokumen dengan identitas visual jelas | Ikuti dokumen |

## Palet (3B)
| Tema | Palet |
|---|---|
| Dokumen resmi, korporat, hukum, notulen | McKinsey atau Refined Professionalism |
| Keuangan formal | Cool Blues atau McKinsey |
| Teknologi, data, startup | Refined Professionalism atau Cool Blues |
| Acara, rekreasi, team building | Serene Nature atau Timeless Elegance |
| Kreatif, promosi | Urban Chic atau Serene Nature |
| Alam, kuliner, budaya, hospitality | Warm Earth Tones |
| Eksekutif, minimalis, cetak hitam-putih | Elegant Minimalism atau Serene Workspace |
Bila dua opsi, pilih yang pertama kecuali sumber memberi alasan lain, dan sebut alternatif kedua.

## Layout
| Isi | Layout |
|---|---|
| Urutan hari/jam | Timeline |
| Banyak kategori | Executive summary grid |
| Alur persetujuan | Process flow |
| Angka/KPI dominan | Metric dashboard |
Materi padat (lebih dari sekitar 150 kata atau lebih dari 5 modul): pecah jadi 2-3 gambar. Penataan default: seimbang.

## Ilustrasi
| Gaya | Ilustrasi |
|---|---|
| Konsultan | Secukupnya, profesional (ikon monoline + 1 adegan kecil per bagian utama) |
| Ilustratif | Adegan flat vector |
| Materi hukum/keuangan murni | Ikon monoline |

## Konten
Default "Lengkap + catatan" bila anomali ditemukan di Langkah 0; selain itu "Lengkap". Bila ringkasan sumber sangat pendek, "Ringkas" cukup dan lebih jujur daripada menggembungkan.

## Penyajian data
| Isi | Penyajian |
|---|---|
| Jadwal 3 hari atau kurang | Timeline atau kartu per hari |
| Jadwal per jam sangat banyak | Kartu per hari dengan jam kunci saja |
| Satu angka dominan | Hero number |
| Rincian biaya 3-6 item | Tabel visual atau bar chart horizontal |

## Mode "ikuti rekomendasi semua"
1. Tanyakan platform bila belum disebut (satu-satunya pertanyaan).
2. Terapkan semua default di atas.
3. Langsung tampilkan Langkah 8 (ringkasan), dengan label "(rekomendasi otomatis)" di tiap baris.
4. Tetap lanjut ke Langkah 9 (arahan tambahan) agar pengguna punya satu kesempatan menyela sebelum prompt dirakit.
